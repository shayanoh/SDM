# Swift-written persistence fixtures

Generated by the `FixtureDump` executable (`legacy/SDMKitSwift/Sources/FixtureDump/main.swift`), which builds
fixed values (fixed UUIDs, strings and numbers; no `UUID()`, `Date()` or randomness) and writes
them with the real Swift encoders. Do not edit by hand. Regenerate with:

```bash
cd /Users/shayanoh/programming/SDM/legacy/SDMKitSwift
swift run FixtureDump /Users/shayanoh/programming/SDM/sdm-core/fixtures/swift
```

Re-running must produce no `git diff`.

Key order: `JSONEncoder` without `.sortedKeys` (used by `JSONStateStore`, `ResumeSidecar.save`
and the media types) emits keys in a per-process order, so for those files the dumper takes the
production encoder's bytes and re-serializes them with sorted keys and pretty printing. The
content is exactly what the encoder produced; only key order and whitespace are normalized.
`quality_preferences.json` contains Swift `Set`s, whose element order is random per process, so
its arrays are additionally sorted. `binaries_manifest.json` is written verbatim with the
`ManagedBinaries` settings (`.prettyPrinted, .sortedKeys`). The Rust tests compare JSON
semantically.

| File | Produced by | Covers |
|---|---|---|
| `state_rich.json` | `JSONStateStore.save` + `flush` | `PersistedState` v2, 3 packages: all five `ItemState` cases (incl. `failed`), all five `Priority` values and absent priority, `isEnabled` true/false, `isResumable` absent/true/false, single-component HTTP, two-component muxed `.resolved` item, `.wholesale` item, component `lastError`, multi-range `RangeSet`, `metadata`, package `note`, odd URLs (see below) |
| `state_minimal.json` | `JSONStateStore` | one package, one item, every optional field absent |
| `state_legacy_flat.json` | literal JSON, verified with the real `JSONDecoder` and `JSONStateStore.load` | `formatVersion` 1, flat items (`url`, `filename`, `totalBytes`, `completed`, ...) with no `components`/`sourceURL` |
| `sidecar_rich.json` | `ResumeSidecar.save(to:)` | every field set |
| `sidecar_minimal.json` | `ResumeSidecar.save(to:)` | optional fields absent, empty `RangeSet` |
| `binaries_manifest.json` | `BinariesManifest` with the `ManagedBinaries.saveManifest` encoder | every field set, nightly channel |
| `resolved_media.json` | `JSONEncoder` | a `ResolvedMedia` with `sourceURL` and the formats of `media_formats.json` |
| `media_formats.json` | `JSONEncoder` | every `MediaKind`, `MediaDelivery`, `VideoCodec`, `AudioCodec` and `MediaContainer` case, including `other(...)`, with `filesize`/`filesizeApprox`/`tbr` present and absent |
| `format_choices.json` | `JSONEncoder` | a muxed `FormatChoice` and a wholesale one |
| `quality_preferences.json` | `JSONEncoder` | `QualityPreferences.default` (sets sorted) |
| `themes/` | copy | every file of `legacy/SDMKitSwift/Sources/SDMCore/Resources/Themes/` |

Notes for readers of these files:

- `DownloadItem` has no "quality choice" field; `FormatChoice` is not stored in the item, so it
  has its own fixture.
- URLs are stored as the string `URL.absoluteString` returns. Foundation's `URL(string:)`
  percent-encodes a string that contains non-ASCII characters as a whole, which turns an
  existing `%20` into `%2520` (see the `EXAMPLE.com:443` / `ü` item). The item with only
  `%20` keeps it. Host case, the `:443` port, a trailing dot and an empty query are preserved.
- The component and item UUIDs are fixed and distinct; uppercase/lowercase is Swift's (`UUID`
  encodes uppercase in the encoder outputs; the hand-written literals use what the tests use).
